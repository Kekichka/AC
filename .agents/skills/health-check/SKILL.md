# Health Check Skill

Ця навичка використовується для швидкої валідації стану сервісу:
1. Запуск тестового запиту до `/api/health`.
2. Перевірка HTTP статус-коду (очікується 200).
3. Валідація наявності полів `status: "ok"` та `timestamp`.

## Виконання
Використовуйте скрипт `scripts/check.sh` або команду curl.
