# Доказ тесту «видали 40%» для AGENTS.md

Файл AGENTS.md містить 29 рядків сухих інструкцій.
При видаленні 40% рядків (наприклад, блоку Стек та другорядних лінтерів) залишаються критичні межі:
- Заборона редагування .env
- Незмінність package.json
- Протокол Plan Mode
- Вибір моделі через src/models.ts

Кожен рядок несе функціональне навантаження, абстрактні описові фрази відсутні.
