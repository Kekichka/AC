# Рішення про заміну моделі

**Що змінено:**
Хмарну модель `gemini-3.8-flash` замінено на `gemini-3.6-flash` в обробнику `app/api/agent/route.ts`.

**Числа «ДО» (gemini-3.8-flash):**
- Затримка: Неможливо виміряти (стабільна помилка `HTTP 503 UNAVAILABLE` через `high demand` або жорсткий ліміт у 20 запитів/день на free-tier).
- Успішних структурованих виходів: 0 з 1.

**Числа «ПІСЛЯ» (gemini-3.6-flash):**
- Затримка: ~4.1 - 5.2 секунди на запит.
- Успішних структурованих виходів: 1 з 1.
- Токени: Вхідні 196 (з них 0 з кешу), Вихідні 122.
- Вартість: $0.000000 фактично ($0.014 за прайсом за мільйон токенів).

**Причина заміни:**
Критична нестабільність базової моделі `gemini-3.8-flash` на безкоштовному тарифі через наплив запитів. Модель `gemini-3.6-flash` надає гарантовану доступність, має ідентичний API та швидко генерує валідні структуровані виходи. 

**Ризики заміни:**
1. Політика даних Google: безкоштовний рівень AI Studio дозволяє використання даних для навчання моделей, тому через хмару пропускається лише код шаблону і публічний AGENTS.md.
2. Дата зняття (Deprecation date): для gemini-3.6-flash потрібно контролювати сторінку документації Google, оскільки застарілі моделі відключаються швидше за флагманські. Очікувано переживе захист лабораторної роботи.
