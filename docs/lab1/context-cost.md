# Оцінка впливу інструментів та MCP на розмір контексту (Context Cost)

## 1. Захист чутливих файлів (Заборони)
- Налаштовано `PreToolUse` хук для блокування модифікації `.env` та `.env.local`.
- **Доказ блокування:**
  - `.agent-log/transcript-claude.jsonl:5` (статус: `denied`)
  - `.agent-log/transcript-gemini.jsonl:5` (статус: `denied`)

## 2. Вимірювання вартості контексту для MCP-сервера
При підключенні інструментів через протокол MCP (Model Context Protocol) описи функцій та JSON-схеми аргументів передаються у системний промпт при кожному запиті користувача.

| Тип інструменту | Кількість інструментів | Орієнтовний обсяг схеми (символи) | Витрата контексту (вхідні токени) | Вартість на 1000 запитів (Claude 3.5 Sonnet / Gemini Flash) |
|---|---|---|---|---|
| Базові інструменти (View/Write/Bash) | 3 | ~1,200 | ~300 токенів / запит | ~$0.90 / $0.02 |
| Додатковий MCP-сервер (напр. Git / Database) | 8 | ~4,500 | ~1,125 токенів / запит | ~$3.38 / $0.08 |
| Навичка `health-check` (on-demand) | 1 (лише опис) | ~350 | ~85 токенів / запит | ~$0.25 / $0.006 |

### Висновок:
Навички (Skills) значно економніші за важкі MCP-сервери, оскільки їхній повний скрипт завантажується лише в момент потреби, не перевантажуючи початковий системний промпт моделі.
