# Вступ (Чернетка курсової роботи)

**Тема:** AI-асистент для генерації тестових сценаріїв (Test Cases Generator).

**Проблема:**
Написання вичерпних тест-кейсів вручну є рутинною, ресурсомісткою задачею, яка забирає значну частину часу QA-інженерів і часто супроводжується людським фактором (пропуск граничних значень, edge-cases).

**Для кого ця система:**
Для QA Manual та Automation інженерів, бізнес-аналітиків та розробників.

**Як система розв'язує проблему:**
Система на базі LLM-агентів автоматично аналізує текстові вимоги, User Stories або код і генерує структурований набір тест-кейсів (включаючи позитивні, негативні та граничні сценарії). 
Агент кодування (який ми тренуємо в лабораторних) у майбутньому зможе не лише планувати тести, а й самостійно генерувати `.test.ts` файли та валідувати їх через Vitest / Playwright у циклі.
