# Рубрика оцінювання судді (ДО ітерації)

## Вимір 1: `acceptance_met`
- `pass`: Усі команди перевірки виконані успішно.
- `fail`: Хоча б одна команда впала або повернула помилку.
- `unknown`: Немає виводу або сталася внутрішня помилка.

## Вимір 2: `scope_respected`
- `pass`: Зміни відповідають завданню.
- `fail`: Змінено файли, які не стосуються задачі.
- `unknown`: Не вказано перелік файлів.
