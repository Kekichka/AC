# Фабрика задач: черга, виконавець, артефакт на кожну задачу (Крок 00)

- **Дата:** 2026-10-21 · **Репозиторій:** [https://github.com/Kekichka/AC](https://github.com/Kekichka/AC)
- **Шлях агента:** Gemini CLI (`gemini-cli`), модель `gemini-3.8-flash` / `gemini-2.5-flash`
- **Чому саме цей:** Безкоштовний доступ через Google AI Studio з добовими квотами без ризику непередбачуваних витрат; наявний ключ API у `.env.local`.
- **Режим дозволів:** `dontAsk` із явним списком дозволених інструментів (`Read, Edit, Bash(npm test *), Bash(npm run typecheck *)`).
- **Ізоляція:** `git worktree`, команда створення дерева:
  `git worktree add -b harness/<id> ..\harness-runs\<id> main`

## 1. Форма задачі

| Поле | Тип | Що означає |
|---|---|---|
| `id` | рядок | Унікальний ідентифікатор задачі (`t-01`, `t-02`...). Використовується для назви гілки, теки прогону та звіту. |
| `input` | рядок | Текстова інструкція для агента: які файли змінити та що зробити. |
| `acceptance` | масив рядків | Машинні команди перевірки успіху (`npm run typecheck`, `npm test -- tests/...`). |
| `budget` | обʼєкт | Ліміти: `max_turns` (ціле), `max_usd` (число), `timeout_s` (таймаут виконання). |
| `files` | масив рядків | Перелік файлів кодової бази, яких торкається задача. |

Черга: `docs/lab3/tasks.jsonl`, задач: **6** (всі задачі сформульовані на основі власного коду репозиторію Лабораторних 1–2).
