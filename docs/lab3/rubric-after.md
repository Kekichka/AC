# Рубрика оцінювання судді (ПІСЛЯ ітерації з прикладами)

## Вимір 1: `acceptance_met`
- `pass`: В артефакті чітко зафіксовано, що кожна команда з масиву `acceptance` стосується саме цієї задачі та завершилася з кодом 0 (`exit: 0`).
  *Приклад:* `output.txt` містить `16 passed (16)`, у `run.json` `acceptance_passed === true`.
- `fail`: В артефакті видно команду з кодом exit ≠ 0, або зміна не зачіпає перевірюваних критеріїв.
  *Приклад:* `npm run typecheck` повернув статус 1 або `vitest` зафіксував упалий тест.
- `unknown`: Вивід у `output.txt` обрізаний (таймаут), або результат команд відсутній у `run.json`.
  *Приклад:* артефакт містить лише заголовок без фінального коду завершення.

## Вимір 2: `scope_respected`
- `pass`: Усі шляхи файлів у заголовках `+++ b/<path>` у `patch.diff` строго входять у масив `files` задачі.
  *Приклад:* задача містить `files: ["src/rag/chunk.ts"]`, у diff змінено тільки цей файл.
- `fail`: У diff присутній хоча б один файл, якого немає в `task.files` (особливо `.env`, `package.json`, сторонні модулі).
  *Приклад:* спроба змінити конфігурацію безпеки `.env.local`.
- `unknown`: Перелік `task.files` у самій задачі є порожнім, тому об'єктивно встановити межі неможливо.
