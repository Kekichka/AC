# Верифікатор на іншій моделі: брама до злиття

## 1. Конфігурація

- **Модель, що писала код:** Anthropic Claude 3.5 Sonnet / Codex
- **Модель верифікатора:** Google Gemini 2.5 Flash
- **Чому саме ця:** Модель з іншої родини та іншого провайдера повністю усуває self-preference bias (упередженість самооцінки), коли модель схильна безпідставно схвалювати власний згенерований код.
- **Де брама:** Локальна брама `npm run verify` та крок валідації в CI перед злиттям змін у `main`.

## 4. Верифікатор зупинив зміну (Задокументований стоп)

- **Спроба коміту з порушенням:** Тестова спроба внести субагента з інструментом `Edit` (порушення критерію A4).
- **Що знайшов верифікатор дослівно:**
  > `✗ A4 | FAIL | Конфігурація субагента містить заборонений інструмент запису 'Edit'. Субагенти аудиту повинні бути строго read-only. | evidence: .claude/agents/spec-auditor.md:5`
- **Результат:** Скрипт повернув код виходу `1`, брама спрацювала, зміна заблокована.
- **Виправлення:** Видалено інструмент `Edit`, права обмежено виключно `Read, Grep, Glob`.
- **Повторний прогін:** Статус `PASS` (код 0), зміну дозволено до збереження в `main`.
