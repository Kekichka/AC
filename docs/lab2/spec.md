# Специфікація: асистент по колекції документів MCP та архітектури агентів

Автор: Student · Дата: 2026-10-13 · Версія: v1

## 1. Задача й користувач

- Хто користувач: Розробник агентних систем та інженер розширень LLM, який інтегрує або розробляє MCP-сервери (Model Context Protocol).
- Яке питання він ставить і що робить із відповіддю: Ставить технічні питання щодо протоколу JSON-RPC, типів ресурсів, схем інструментів, безпеки і життєвого циклу MCP; використовує відповідь для написання та верифікації коду MCP-сервера.
- Що він робить сьогодні без асистента: Вручну шукає у специфікаціях та репозиторіях, витрачає 10–20 хвилин на пошук деталей валідації параметрів, часто пропускає вимоги безпеки та формати JSON-RPC помилок.

## 4. Non-goals v1 (чого асистент НЕ робить)

- Не підтримує голосовий або мультимодальний (зображення/відео) ввід.
- Не виконує запис чи модифікацію зовнішніх баз даних та файлової системи користувача (строго read-only консультант).
- Не підтримує довільні запитання поза темою MCP та агентних систем (наприклад, кулінарія чи загальна історія мають відхилятися або маркуватися як нерелевантні).
- Не забезпечує постійного збереження історії бесід між перезапусками CLI-сесій (stateless на рівні CLI-запитів).

## 5. Обсяг v1

- Входить:
  - Індексація та розбиття на фрагменти 16 документів корпусу.
  - Гібридний пошук (BM25 / ключові слова + семантичний векторний пошук).
  - Формування відповіді з обов'язковим списком використаних джерел (`must_cite`).
  - Верифікація відповідей субагентом-аудитором та окремою моделлю-суддею.
  - Експорт власних інструментів пошуку через MCP-сервер.
- Не входить до v1 (на майбутнє):
  - Повноцінний UI-вебінтерфейс з веб-сокетами для стрімінгу чату.
  - Автоматичне завантаження нових документів за URL у реальному часі.

## 7. Обмеження

- Бюджет: Безкоштовні ліміти провайдерів (Google Gemini API / Anthropic API / Groq).
- Мережа в CI: Усі автоматичні тести валідації та схем проходять суворо offline без зовнішніх викликів.
- Апаратні: Локальне виконання на процесорі без обов'язкової наявності GPU.
- Часові: Заняття 05–08, фінальне подання до початку заняття 09.
