# AGENTS.md

## Стек
- TypeScript (strict), Next.js (App Router), Vitest, Playwright.

## Команди
- npm run doctor — перевірка середовища та агентів.
- npm test — модульні тести (Vitest), без мережі.
- npm run typecheck — строга перевірка типів, без емісії.
- npm run lint — перевірка коду (ESLint).
- npm run build — продакшн-збірка.

## Межі
- .env і .env.* агент ніколи не читає, не виводить і не редагує.
- package.json — залежності не змінюються без прямої згоди людини.
- Тести не ходять у мережу і не викликають платні API.
- Не модифікувати файли поза межами поставленої задачі.

## Домовленості
- Модель обирається роллю з `src/models.ts` (наприклад, `MODELS.cheap`), а не вільним рядком.
- Ціни й дати зняття моделей звіряються зі сторінкою вендора, а не з пам'яті.

## Режим плану (Plan Mode)
- Якщо задача на планування — агент НЕ створює і НЕ змінює жодних файлів.
- Результат плану: (1) точний шлях до файлів, (2) метод/маршрут/JSON-схема, (3) diff-план, (4) припущення і ризики.
